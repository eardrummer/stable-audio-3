# Stable Audio 3 Local Studio & Blending Workstation

This repository contains the **Stable Audio 3 Local Studio Workstation**, an Apple Silicon native (MLX) web application for real-time generative audio synthesis and dual-source audio blending experiments.

---

## 🚀 Quick Start

Run the studio launcher script from the repository root:

```bash
./run_studio.sh
```

Then open your browser to **`http://localhost:5173`**.
